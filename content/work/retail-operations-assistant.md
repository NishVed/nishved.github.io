A multinational energy retailer's operational and commercial teams needed natural-language access to KPIs,
forecasting, inventory, sales, and financial analytics, without generating reports or navigating
dashboards by hand — across multiple business units and countries with different data-access
scopes.
<!--more-->

The assistant is embedded directly in the client's existing back-office system, with Semantic Kernel
routing intent to specialized agents — forecasting, executive summaries, contextual
visualization — over existing Power BI semantic models rather than a rebuilt analytics layer.
Multi-tenancy runs through Azure Entra ID combined with Power BI Row-Level Security scoped per
business unit and country, so the same assistant serves every entity without duplicating access
control logic.

**My role:** led the architecture design end-to-end; designed the conversational-analytics layer
over Power BI with RLS passthrough and the multi-tenant security model.

**Stack:** Azure OpenAI, Semantic Kernel, Azure AI Foundry, Microsoft Fabric, Power BI Embedded,
Azure Entra ID.
